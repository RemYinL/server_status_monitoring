# 07 relay 主机硬件调研（2026-10-15）

## 1. 现有设备结论：TL-RAC1950G 不可用作 relay 主机

用户现有路由器 TP-LINK TL-RAC1950G（TPAC1950G 易展版，AC1900 双频千兆，易展 Mesh）。经检索拆机资料（恩山论坛 TTL 启动日志，thread-8297666）确认硬件：

| 部件 | 规格 | 对 OpenWrt 的意义 |
|---|---|---|
| SoC | MediaTek MT7626 | 无 OpenWrt 主线支持，TOH 无任何条目 |
| RAM | 32 MiB | 远低于 OpenWrt 可用下限（128MB），系统无法正常启动 |
| Flash | XM25QH32B，4MB | OpenWrt 已放弃 4MB 闪存设备多年；连官方固件本身都需高度精简 |
| 第三方玩法 | 仅编程器互刷同系列 TP 官方固件（WDR7650/YR900MG） | 封闭固件，无法运行自定义服务 |

**结论：该设备无法刷 OpenWrt，也不具备运行 ssm-relay 的任何条件。** 其正确定位是继续专职承担 AP / 易展 Mesh 无线覆盖，不要在其上投入刷机尝试（变砖风险高且零收益，社区共识「刷进去也没用」）。

**（本节为完整备选对比；最终定案为方案 ④ 新购 N100 软路由，见第 4 节。方案 ⑥ 保留为可选第二观察者。）**

决策时考虑的三点约束：
1. relay 资源需求极低（内存 < 30MB、CPU ≈ 0），决策变量主要是成本、可靠性与扩展性。
2. 与服务器同局域网是双路探测（lan + tailscale，见 03 文档）的前提，①②③④ 满足，⑥ 不满足。
3. 家庭网络出口设备宕机时全家断网，局域网内 relay 推送同样不可达——此固有边界由方案 ⑥ 或 UptimeRobot 外部兜底覆盖（见 05 风险登记），不必为消除该边界牺牲双路探测能力。

## 3. 部署约束（以定案的 N100 x86 软路由为准；ARM 方案存档备查）

- 交叉编译目标：`x86_64-unknown-linux-musl`（N100，定案）/ `aarch64-unknown-linux-musl`（ARM 存档方案），静态单二进制，scp 拷贝即用。
- 进程托管：PVE + Debian LXC 或裸 Debian 用 systemd（复用 deploy/ unit）；OpenWrt 形态用 procd init 脚本。
- 存储：心跳台账（SQLite）放 tmpfs（`/tmp/ssm-relay/`），每 5 分钟异步快照至持久分区，避免 TF 卡/eMMC 频繁写入磨损。
- 网络：relay 主机使用内网固定 IP（DHCP 静态绑定），agent.toml / relay.toml 中探测路径同时配置 lan 与 tailscale 地址。
- Bark 推送依赖 relay 主机的公网出站（HTTPS 至 api.day.app 或自建 Bark server），无需入站端口映射。

## 4. 采购决策（2026-10-15 定案：新购 N100 软路由）

用户已定案**新购软路由**，放弃利旧方案（无闲置盒子/树莓派的确认成本）。选型依据 2026 年市场主流共识：

### 4.1 推荐配置（基准清单）

| 部件 | 要求 | 理由 |
|---|---|---|
| 平台 | Intel N100（Alder Lake-N，4C4T，TDP 6W） | 2026 年入门软路由性价比标杆，性能约为 J4125 两倍，relay 负载下占用 ≈ 0 |
| 网口 | ≥ 2× 2.5G，**芯片必须 Intel i225/i226** | Realtek 网卡在 Linux 下驱动稳定性差，是最大避坑点；4 口版本可留 WAN/LAN/IPTV/隔离扩展位 |
| 内存 | 8GB DDR5 起步 | 4GB 会导致 PVE/Docker 场景卡顿；relay 本身 < 30MB，余量为网关与扩展职能留 |
| 存储 | 128GB M.2 SSD（注意插槽需支持 NVMe，部分低价机型仅 SATA） | 系统 + PVE/LXC 镜像余量 |
| 散热 | 无风扇被动散热优先 | 7×24 静音；避免夏季降频 |
| 参考预算 | 准系统 400–600 元 + 内存/SSD 约 200 元，整机 600–800 元 | 畅网、倍控、零刻 EQ12 等成熟品牌 |

### 4.2 组网方式

RAC1950G 保留作 AP/易展 Mesh 无线覆盖，新软路由的接入位置二选一：

- **主路由模式**：N100 软路由拨号/当网关，RAC1950G 改 AP 模式挂其下。网络能力最强，但改动大、割接有断网窗口。
- **旁路网关模式（默认推荐）**：软路由仅作 relay 主机 + 可选旁路服务，不动现有 RAC1950G 主路由结构。接线一根（LAN 口接交换机/RAC1950G LAN），零割接风险；relay 的双路探测能力完全不受影响。

### 4.3 采购验收清单（到货后）

- [ ] 确认网卡芯片为 Intel i225/i226（`lspci | grep -i eth`）
- [ ] 安装 PVE（或 OpenWrt/Debian，按 02 文档 4.2a 形态选择）
- [ ] 内网固定 IP（DHCP 静态绑定）
- [ ] 安装 Tailscale 并加入既有 tailnet
- [ ] 交叉编译 `x86_64-unknown-linux-musl` relay 二进制部署（M5 执行）
